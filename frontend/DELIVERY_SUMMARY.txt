🚀 COMO COMEÇAR
═══════════════════════════════════════════════════════════════

1. INSTALAR DEPENDÊNCIAS
   $ cd frontend
   $ npm install

2. CONFIGURAR AMBIENTE
   Editar .env.local:
   NEXT_PUBLIC_BACKEND_URL=http://localhost:8080/api

3. INICIAR BACKEND (porta 8080)
   $ cd backend
   $ ./mvnw spring-boot:run

4. INICIAR FRONTEND
   $ cd frontend
   $ npm run dev
   
   Acesse: http://localhost:3000
